PAGODE DO TINEGA — SITE PRONTO PARA PUBLICAR
=============================================

CONTEÚDO
  index.html ........ página principal
  img/ .............. fotos (WebP + JPG), logo e ícones
  og-image.jpg ...... capa da prévia no WhatsApp / redes
  favicon.ico, favicon-32/192.png, apple-touch-icon.png, icon-512.png, site.webmanifest ... ícones
  404.html .......... página de erro (volta para o início)
  _headers .......... cache e segurança (Netlify / Cloudflare Pages)
  robots.txt

ANTES DE PUBLICAR (1 passo obrigatório)
  Abra index.html num editor de texto e use "Substituir tudo":
     SEU-DOMINIO.com.br   →   seu domínio real   (ex.: pagodedotinega.com.br  ou  tinega.netlify.app)
  Sem isso a capa não aparece ao colar o link no WhatsApp.

COMO PUBLICAR — opção mais fácil (Netlify, grátis)
  1. Acesse https://app.netlify.com/drop  (crie conta grátis se pedir)
  2. Arraste ESTA PASTA inteira para a página
  3. Em "Site configuration > Change site name" escolha o nome → vira  https://NOME.netlify.app
  4. Se ainda não trocou o domínio no index.html, troque por  NOME.netlify.app  e arraste de novo
     (Deploys > arraste a pasta atualizada)
  Domínio próprio: Domain management > Add a domain (compre no registro.br, ~R$ 40/ano)

OUTRAS HOSPEDAGENS
  Vercel, Cloudflare Pages, GitHub Pages, Hostinger/HostGator: envie o CONTEÚDO desta pasta
  para a raiz do site (index.html direto na raiz, não dentro de subpasta).
